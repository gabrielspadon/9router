# Changelog

## 0.1.0

Initial TokenProxy release.

TokenProxy is a local AI routing gateway and dashboard. It exposes one
OpenAI-compatible endpoint at `/v1/*`, translates each request into the format
the chosen upstream expects, and falls back across models and accounts.

This is the first release under the TokenProxy name and version series. It
carries no inherited release history, no predecessor state import, and no
compatibility path to any earlier project.
