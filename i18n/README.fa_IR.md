# 9Router

> این یک خلاصهٔ کوتاه ترجمه‌شده است. مستندات اصلی به زبان انگلیسی هستند، در
> [README.md](../README.md) و [docs/README.md](../docs/README.md).

<div dir="rtl">

9Router یک دروازهٔ محلی مسیریابی هوش مصنوعی به همراه یک داشبورد است. تنها یک
نقطهٔ پایانی سازگار با OpenAI روی `/v1/*` ارائه می‌دهد، هر درخواست را به قالبی
که ارائه‌دهندهٔ انتخاب‌شده انتظار دارد ترجمه می‌کند، و میان مدل‌ها و میان
حساب‌ها جابه‌جا می‌شود. به این ترتیب یک پیکربندی واحد در سمت کلاینت همچنان کار
می‌کند، حتی وقتی سهمیهٔ یک ارائه‌دهنده تمام شود، محدودیت نرخ اعمال شود یا خطا رخ
دهد.

</div>

## نصب

```bash
npm install -g 9router
9router
```

<div dir="rtl">

داشبورد روی `http://localhost:20128/dashboard` و رابط سازگار با OpenAI روی
`http://localhost:20128/v1` سرو می‌شود. نخستین ورود از `INITIAL_PASSWORD`
استفاده می‌کند که مقدار پیش‌فرض آن `123456` است. آن را تغییر دهید.

مراحل کامل در [docs/getting-started.md](../docs/getting-started.md) آمده است.

</div>

## وضعیت انشعاب

<div dir="rtl">

این مخزن یک انشعاب (fork) است که به‌طور مستقل از
[decolua/9router](https://github.com/decolua/9router) نگهداری می‌شود. پروژهٔ
بالادست را دنبال می‌کند و در عین حال اصلاحات و یکپارچه‌سازی‌های محلی خود را با
زمان‌بندی خودش نگه می‌دارد. نام 9Router، تاریخچهٔ پروژهٔ بالادست، مجوز و
انتساب نویسندگان همگی حفظ شده‌اند.

پروژهٔ بالادست تنها یک مرجع فقط‌خواندنی است و تمام توسعه اینجا انجام می‌شود.
این انشعاب مورد تأیید پروژهٔ بالادست نیست و از طرف آن سخن نمی‌گوید.

متن کامل، از جمله فرآیند همگام‌سازی، در بخش "Fork status" فایل
[README.md](../README.md) انگلیسی آمده است.

</div>
