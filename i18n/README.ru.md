# 9Router

> Краткое переведённое изложение. Основная документация написана на английском
> языке, см. [README.md](../README.md) и [docs/README.md](../docs/README.md).

9Router это локальный шлюз маршрутизации запросов к моделям ИИ вместе с
панелью управления. Он открывает одну совместимую с OpenAI точку входа по пути
`/v1/*`, переводит каждый запрос в формат выбранного поставщика и
переключается между моделями и учётными записями, поэтому одна настройка
клиента продолжает работать, когда у поставщика заканчивается квота, срабатывает
ограничение частоты запросов или происходит сбой.

## Установка

```bash
npm install -g 9router
9router
```

Панель управления доступна по адресу `http://localhost:20128/dashboard`, а
совместимый с OpenAI API по адресу `http://localhost:20128/v1`. Первый вход
использует `INITIAL_PASSWORD`, значение по умолчанию `123456`. Замените его.

Полное описание находится в
[docs/getting-started.md](../docs/getting-started.md).

Этот репозиторий является независимо поддерживаемым форком
[decolua/9router](https://github.com/decolua/9router). Он следует за

графику. Название 9Router, история вышестоящего проекта, лицензия и указание
авторства сохранены.

Вышестоящий проект служит справочным материалом только для чтения, вся
разработка ведётся здесь. Этот форк не одобрен вышестоящим проектом и не
выступает от его имени.

Полный текст, включая процесс синхронизации, находится в разделе "Fork status"
английского [README.md](../README.md).
